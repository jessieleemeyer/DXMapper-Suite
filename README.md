# DXMapper Suite

A one-stop Windows program for FM DXing. It has three parts that work together:

- **FM Tuner** - an RTL-SDR / HackRF FM receiver with RDS decoding, seek, presets and a phone remote.
- **RDS Monitor** - shows everything the station's RDS sends: PI, PS, RadioText, RT+, song search buttons, AF, TMC and more.
- **DX Mapper** - logs stations on a map and in a Log Book, looks up FCC / Wikipedia details and logos, and can add stations that send no RDS.

## Download

Get the newest ZIP from [Releases](https://github.com/jessieleemeyer/DXMapper-Suite/releases/latest), unzip it, and follow `QUICK_START.txt` (or `QUICK_START.pdf`). `OWNERS_MANUAL.pdf` covers every feature, and `WHATS_NEW.txt` lists the changes.

## Updating

Copy the new files over your old folder. Your presets, layouts, logs and logos live in `settings\`, which updates never touch.
